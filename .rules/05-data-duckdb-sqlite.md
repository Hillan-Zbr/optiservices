# Règles Données (DuckDB / SQLite)
- DuckDB : Traitements analytiques et opérations spatiales (extension `spatial`).
- SQLite : Persistance légère (configurations, utilisateurs, historiques).
- Schéma : Séparer `clients`, `depots`, `vehicules`, `tournees_historique`.
- Performance : Agréger les données d'entrée en une seule requête SQL.
